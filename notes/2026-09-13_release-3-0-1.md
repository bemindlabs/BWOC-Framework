# 2026-09-13 — Release 3.0.1 (`v2026.9.13-1`)

This patch release is the first after 3.0.0. Every fix in it came up while rolling 3.0 out to the three-host fleet the same day.

## What shipped
- **#501:** chat connectors now keep a session file per chat, and each bridged turn carries `Principal::Platform`.
- **#503:** `bwoc init` no longer overwrites an existing `.bwoc/agents.toml`. It refuses when that path exists but isn't a regular file.
- **#505:** `bwoc new` stamps `SPEC_VERSION_CURRENT` (3.0) instead of a hardcoded 2.0.
- **#504:** the formula moves to `v2026.9.13-0` (the formula for this release follows after the tag).
- The README Status badge is updated; it still said Phase 5.

## Decisions
- **#506 is held out** (bwoc-bot `[bot]` block and limited public mode). It is a feature (`### Added`), so under semver it ships as 3.1.0, not in a patch. Its auto-merge was disabled until this tag was cut.
- **Tag `-1` on the same day:** 3.0.0 is `v2026.9.13-0`, so this is a same-day re-issue per RELEASING.

# 2026-09-19 — Release 3.3.0 (`v2026.9.19-0`)

Minor release on top of 3.2.0.

## What shipped
- **Runtime R4a** (#532): several conversations per directory — `bwoc --new`, `bwoc --session <id>`, `bwoc session list`, `bwoc session fork` and `bwoc session rm`; 3.2 conversations migrate on first open, keeping their id.
- **Bare `bwoc` on vendor coding CLIs** (#529 → #530): `--backend claude|codex|agy|kimi|grok|copilot` execs that CLI on its own login; `[defaults] backend` stands in for `[runtime] backend`.
- **Chat TUI controls** (#531): `Ctrl-C` is the only exit, `↑/↓` scroll, `←/→` edit, a controls footer, no idle repaint (native copy works).

## Decisions
- **Minor, not patch:** `### Added` (R4a).
- **Scope cut from the plan (user's call, 2026-09-19):** the runtime plan had 3.3 = R4–R5. 3.3.0 ships R4a only; R4b (undo/redo), R4c (protocol Cancel/SetModel/diff/cost) and R5 (TUI: in-TUI session switching/fork via slash commands, Markdown rendering) move to 3.4. The small chat-pane control refinements (#531) shipped independently.

## Known residuals
- No in-TUI session switching or fork (R5 slash commands).
- Markdown is still not rendered in the TUI (R5).

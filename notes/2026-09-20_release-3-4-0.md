# 2026-09-20 — Release 3.4.0 (v2026.9.20-0)

A one-day release on top of 3.3.0: the chat input gains `/` commands and `@` file mentions, and `bwoc dashboard` starts its deprecation.

## What shipped
- **`/` commands and `@` file mentions in the chat TUI** (#535): `/help`, `/clear`, `/mode [default|accept_edits|bypass]`, `/quit`, `/exit` run in the TUI over existing `ChatInput` (no protocol change); `@` completes project files and attaches each text file inside the workdir (32 KB cap, `..`/symlink escapes and binaries refused). Fleet panes opt out so `@agent` routing is unchanged.
- **`bwoc dashboard` deprecated** (#537): warn-only (no 1:1 command to rewrite onto), replaced by `bwoc fleet` / `bwoc chat <agent> --tui --fleet`. Removal in 4.0.
- **`bwoc session fork` message** (#536) names the conversation bare `bwoc` resumes, and never prints `--session ?`.

## Decisions
- **Minor, not patch:** `### Added` (the input-line surface).
- **`@` inlines file content** rather than completing a bare path — the operator's call; capped and workdir-confined, sent as `LocalOperator` so trust gating is unchanged.
- **Deprecation, not removal, for `dashboard`** — the compatibility contract allows removal only at a major.
- `/new`, `/session` and `/compact` are still out: they need the R4c/R5 protocol work.

## Status / deferred
- R4b (undo/redo), R4c (protocol Cancel/SetModel/diff/cost) and R5 (in-TUI session switching, Markdown rendering) remain for a later release.
- The file walk behind `@` does not honour `.gitignore`.

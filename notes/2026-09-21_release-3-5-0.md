# 2026-09-21 — Release 3.5.0 (v2026.9.21-0)

The rest of the runtime plan: R4b, R4c and R5 all land, closing the R4/R5 block that 3.3.0 opened with R4a.

## What shipped
- **R4c** (#540): `Cancel` / `SetModel` inputs, `Cancelled` / `ModelChanged` / `Diff` events, `TurnEnd.cost_usd`. `Esc` cancels a turn, `/model` switches models, file-mutating tools emit a bounded unified diff, and cost is shown only when the provider reports one.
- **R5** (#541): `/sessions`, `/session <id>`, `/new`, `/fork [<id>]` reopen the harness on another conversation in the same terminal; assistant turns render as Markdown.
- **R4b** (#542): `/undo` and `/redo` over a per-conversation edit journal, refusing to touch a file that changed since.

## Decisions
- **Minor, not major:** every protocol addition is additive (`#[serde(default)]` on the new `TurnEnd` field, new event variants an older frontend ignores).
- **Three PRs, stacked, merged in order** rather than one mega-PR (CONTRIBUTING §one concern per PR). Each rebase onto `main` was a cherry-pick of the top commit, so the history stays one commit per feature.
- **Provider-reported cost only**, no local price table — the same honesty rule the status line already followed for tokens.
- **Edit journal over a shadow git dir** for undo (operator's call): proportional cost, no second VCS over the operator's repo, and a conflict check instead of a silent overwrite.

## Bugs surfaced and fixed in review
- Diff truncation could split a multi-byte character and panic (#540, caught by Copilot; now cut on a byte-safe newline, with a Thai-text test).
- A session switch while a turn was running would drop the turn (#541); it now refuses and points at `Esc`.
- The undo journal treated *any* read failure as "file absent", so an undo could delete an unreadable file; and a corrupted cursor could underflow (#542). Both fixed with tests.

## Status / deferred
- A cancel during a long `run_command` lands when that command returns.
- `run_command` side effects are outside the undo journal (they surface as conflicts, never as clobbers).
- The journal is never pruned.

# 2026-09-13 — Release 3.1.0 (`v2026.9.13-2`)

Minor release on top of 3.0.1. It carries bwoc-bot phase 1 (#506). That PR changes a security boundary, so it was reviewed before merge.

## What shipped
- **Connector `[bot]` block:**
  - `commands` send fixed replies before the model is involved.
  - `rate_limit_per_min` and `max_input_chars` cap each sender.
- **Limited public mode (`public = true`):**
  - Senders not on the allow-list are served only by DM or by @mention.
  - Their session is locked to the harness `plan` mode (read-only tools) and fails closed if the harness doesn't confirm it.
  - It runs in `.bwoc/public/<platform>-<chat>/`, which holds only a copied `AGENTS.md` and a manifest with `deepMemoryCmd` removed.
  - Public senders never share a session or team-chat context with allow-listed senders.
- **Symlink-safe confinement:** `ToolContext::resolve_path` checks the canonical path of the deepest existing ancestor, and applies to every agent, not only public sessions.
- **Connector `schema_version`** uses `SchemaVersion`; `bwoc migrate` stamps `connectors/*.toml`.

## Decisions
- **Minor, not patch:** these are `### Added` features.
- **Same-day tag `-2`:** 3.0.0 is `-0` and 3.0.1 is `-1`.

## Known residuals
- `--chat` has no per-turn token cap, so cost is bounded only by rate limit × message size (documented in THREAT-MODEL).

# 2026-09-15 — Release 3.2.0 (`v2026.9.15-0`)

Minor release on top of 3.1.0. It completes runtime phases R0–R3 ("BWOC as its own coding agent") and the lean pass from the 2026-09-15 audit.

## What shipped
- **Runtime R0–R3** (#519, #522, #523, #526): bare `bwoc` opens a zero-setup coding session; `bwoc auth`; project/user `config.toml`; a session system prompt; chat on the batch retry, MCP, capability-gate and turn-executor paths; context-window compaction; streamed thinking; coding tools.
- **TUI fixes found by live e2e** (#524, #525, and inside #523/#526): permission keys no longer consume typing, long rows no longer hide the answer, harness stderr goes to a log, `run_command` `timeout_secs` is enforced on the sandboxed path.
- **Lean pass** (#514–#518, #520, #521): dead code and stub plugins removed, skills pruned to 5, docs aligned with the code, trust gate warn-by-default, duplicate CLI entry points deprecated.

## Decisions
- **Minor, not patch:** `### Added` features and deprecations.
- **Maintainer sign-offs recorded on the PRs:** interactive chat prompts (rather than denies) on gated calls after untrusted content, while `--headless` denies (#523); `webfetch` / `todo` / `subagent` run in-process from a closed list after the same checks (#526); `todo` asks on untrusted turns for now.

## Known residuals
- Markdown is not rendered in the TUI, and text from separate stream segments can run together on one line (R5).
- `subagent` inner tool calls are not shown in the frontend or counted in turn usage.
- `webfetch` does not catch a public DNS name that resolves to a private address.

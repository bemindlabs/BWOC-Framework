# 2026-09-20 — Release 3.6.0 (v2026.9.21-1)

A gap pass over the chat TUI's `/` surface, plus the context pane. Three PRs (#545–#547).

## What shipped
- **Nine commands from state the session already had** (#545): `/status`, `/tools`, `/cost`, `/retry`, `/save`, and — through a new `EnvironmentInfo` trait the caller implements — `/models`, `/backends`, `/settings`, `/doctor`. The `Ready` event had carried a tool list since the protocol was written; the TUI was discarding it.
- **A fixed context pane** (#546): directory + branch (from `.git/HEAD`), the workspace above the cwd and its agents, the session's id/turns/usage/mode, and the files tools changed. `F3` toggles; under 100 columns it does not draw.
- **Four protocol-backed commands** (#547): `/compact`, `/permissions`, `/mcp`, `/context`, carried by `ChatInput::Compact` and a single `Describe { topic }` → `Described { topic, rows }` pair.

## Decisions
- **A trait per capability, not a dependency**: `SessionControl` (3.5) and now `EnvironmentInfo` keep `bwoc-tui` compile-depending on `bwoc-core` alone, even though the answers come from `bwoc-cli`.
- **One `Describe` input for every read-only question** rather than a variant per topic.
- **Refuse rather than guess**: `/models` only enumerates Ollama; `/compact` says so when `max_context` is `0` instead of folding against a 1-token budget; `/doctor` shells out to the real `bwoc doctor --json`.
- **Deliberately not shipped**: `/workspaces` and `/fleet` — a project session is not in a workspace, and the pane now shows the workspace when there is one.

## Bugs surfaced and fixed in review
- A linked worktree whose `.git` file holds a **relative** `gitdir:` resolved against the process cwd (#546).
- The pane's changed-file list ignored re-edits and grew without bound (#546).
- `/compact` contradicted `/context` when compaction was disabled (#547).
- Row padding counted characters, not terminal columns, so a wide-character label misaligned (#547).

## CalVer slip (worth knowing)
3.5.0 was tagged `v2026.9.21-0` on **2026-09-20** — a day ahead. Rolling back to `v2026.9.20-1` for this release would sort *below* 3.5.0 and stop Homebrew from seeing an upgrade, so 3.6.0 is `v2026.9.21-1` and the tag scheme resyncs with the calendar on the next release cut on or after 2026-09-21.

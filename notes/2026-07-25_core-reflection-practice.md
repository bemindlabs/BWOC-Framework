# 2026-07-25 — Core Reflection (Like / Wish / Next Step) in the self-improvement framework

Added a concrete, repeatable growth ritual to the agent-template's learning-loop
doc, plus a stage-by-stage explanation of how it threads the whole loop.

## What changed

- `modules/agent-template/docs/{en,th}/SELF-IMPROVEMENT` §2.4 **Core Reflection** —
  the Like / Wish / Next Step three-line retrospective, run at the close of every
  task and session. Prong table (what each asks / produces / feeds), honesty rules
  (one line each, Wish = gap not grievance, exactly one owned Next step), a
  template + a worked example, a **stage-mapping table** (what Core Reflection asks
  after Suta / Cintā / Bhāvanā and what the Next step becomes there), and an
  escalation rule (a Wish recurring 3+ times climbs the Curation Pipeline).
- A reciprocal pointer in §4 The Wisdom Loop naming Core Reflection as the ritual
  that drives the loop's arrows.

## Decisions

- **Placed under §2 Cintāmayā, not a new top-level section.** Core Reflection *is*
  reflection made practical; it belongs inside the reflection root, cross-linked
  from §4/§5 rather than bolted on as a parallel structure (Mattaññutā — extend the
  existing spine, don't grow a second one).
- **Grounded in Paccavekkhaṇa (MN 61, the Rāhula instruction)** — review before,
  during, and after every action. Like/Wish is the "after"; Next step seeds the
  "before" of the next task. This keeps the new practice mapped to a canonical
  framework, per the repo's philosophy-grounding rule.
- **"Every stage explained" delivered as the stage-mapping table**, not a new
  narrative section — it reuses the existing Suta/Cintā/Bhāvanā stages and shows
  the ritual operating at each boundary, so the two asks land as one coherent
  addition instead of duplicated prose.
- **Kept it to one line per prong by rule.** The value is the *cheapness* — a retro
  small enough to always run. Anything larger is already a `decision-*`; the rule
  says promote it, which routes depth to the right memory type.
